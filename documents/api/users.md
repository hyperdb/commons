# API: ユーザー（/users）

共通ルールは`/documents/api-conventions.md`を参照。項目の意味は`/documents/Entities.md`を参照。

## ユーザー情報の返却形式

`password_hash`は返さない。

```json
{
  "id": "abcd",
  "user_level": "001",
  "created_at": "2026-10-13 17:00:00",
  "updated_at": "2026-10-13 17:00:00"
}
```

## POST /users/auth/{id} — ログイン認証

- 認証: 不要
- ボディ: `{ "password": "..." }`
- 成功: `200` `data: { "token": "<短縮トークン22文字>" }`
- 失敗: `401`（IDが存在しない場合もパスワード違いと同じ応答にする）
- 備考: 認証時に期限切れトークンを削除する

## GET /users — 一覧取得

- 認証: 必要
- クエリ: `page`, `rows`（共通ルール参照）
- 成功: `200` `data: [ユーザー情報, ...]`

## GET /users/{id} — 詳細取得

- 認証: 必要
- 成功: `200` `data: ユーザー情報`
- 該当なし: `404`

## POST /users — 登録

- 認証: 必要
- ボディ: `{ "id": "...", "password": "..." }`
- 成功: `201` `data: ユーザー情報`
- バリデーションエラー: `400`
- ID重複: `409`

## PUT /users/{id} — 更新（パスワード変更）

- 認証: 必要
- ボディ: `{ "password": "..." }`
- 必要な権限レベル（共通ルールの例外）
  - 自分のパスワード: `001`以上
  - 自分以外のユーザーのパスワード: `111`（システム管理者）のみ
- 成功: `200`
- バリデーションエラー: `400`
- 権限レベル不足: `403`
- 該当なし: `404`

## PUT /users/{id}/level — 更新（権限変更）

- 認証: 必要
- ボディ: `{ "user_level": "..." }`
- 必要な権限レベル（共通ルールの例外）
  - 自分の権限レベル: 変更できない
  - 自分以外のユーザーの権限レベル: `111`（システム管理者）のみ
- 成功: `200`（`data`は空配列）
- バリデーションエラー: `400`
- 権限レベル不足: `403`
- 該当なし: `404`

## DELETE /users/{id} — 削除

- 認証: 必要
- 成功: `200`（そのユーザーのトークンも削除される）
- 該当なし: `404`

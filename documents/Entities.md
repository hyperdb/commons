# 管理対象のエンティティ

列名・型・長さは`/schema.sql`を正本とします。このファイルには各項目の意味と業務ルールのみを記載します。

## ユーザー（user / users）

- **概要**:
  - ユーザーを識別するためのもの
  - 個人運営の各種サイトのコンテンツ管理などを行う上での認証に使用
  - いずれ自分以外の利用者の権限も管理していく
- **項目**
  - `id`:
    - ユーザーを識別するID（ログイン時に入力するもの）
    - 4文字以上32文字以内
    - 使用可能な文字: 半角の英小文字と数字と一部の記号（`-_.`）
      - ただし、先頭と末尾に記号を使うことはできない。
    - `gh-`・`gg-`で始まるIDは外部ユーザー用に予約しているため登録できない
  - `password_hash`:
    - 認証用のパスワードのハッシュ値
    - PHPの`password_hash`で算出されたもの
    - パスワード自体のルール
      - 8文字以上72文字以内（72文字はbcryptの上限）
      - 使用可能な文字: 半角の英数字・記号のみ（空白・全角文字は不可）
      - 英大文字・英小文字・数字・記号をそれぞれ1文字以上含む
    - APIのレスポンスには絶対に含めない
  - `user_level`:
    - ユーザーの権限レベル
      - `000`: 権限なし
      - `001`: 一般ユーザー
      - `010`: 編集可能ユーザー
      - `111`: システム管理者
    - 初期登録時は`001`
    - 変更はシステム管理者のみ（自分自身は変更不可）
  - `created_at`: データ作成日時（追加時に自動設定）
  - `updated_at`: データ更新日時（追加・更新時に自動設定）

## トークン（token / tokens）

- **概要**:
  - ユーザー認証後に渡される一意の識別子
  - 発行したユーザーに紐付ける（API実行時に誰の操作かを特定し、権限レベルを判定するため）
  - 発行時点から60*60秒（1時間）の有効期間（秒数は仮）
  - トークンチェックが正常に完了すると有効期間が延長される
  - ユーザーが削除された場合、そのユーザーのトークンも削除される
- **項目**
  - `token`:
    - UUIDv4（ハイフン付き）で保持
    - ユーザーに渡す際は短縮化したもの（Base64URL・22文字）を渡す
  - `owner`:
    - トークンを発行したユーザーの`users.id`
  - `expired_at`:
    - トークンの有効期限（UNIXタイム）
    - トークンチェックの結果で延長される
  - `created_at`: データ作成日時（追加時に自動設定）
  - `updated_at`: データ更新日時（追加・更新時に自動設定）

## 外部ユーザー（external user / external_users）

- **概要**:
  - GitHub／Googleのアカウントでログインしたユーザー
  - ブログ（`writers`）へのコメントの書き込みユーザーを識別するためだけに使う
  - `users`とは別に管理し、パスワード・権限レベルは持たない（権限レベルは`000`として扱う）
  - 初回ログイン時に登録し、2回目以降のログインで表示名・アバターURLを上書きする
  - 同じ人がGitHubとGoogleの両方でログインした場合は別のユーザーになる
  - メールアドレスとプロバイダーのアクセストークンは保存しない
- **項目**
  - `id`:
    - commons内のユーザーID
    - GitHub: `gh-<GitHubの数値ID>`
    - Google: `gg-<ランダム文字列>`（Googleの`sub`は長さが決まっていないため使わない）
      - ランダム文字列は半角の英小文字と数字の16文字
  - `provider`: プロバイダー（`github`／`google`）
  - `provider_user_id`:
    - プロバイダー側でユーザーを識別するID（GitHubの`id`／Googleの`sub`）
    - `provider`との組み合わせで一意
  - `display_name`:
    - 表示名（GitHubは`name`、未設定なら`login`／Googleは`name`）
  - `avatar_url`: アバター画像のURL（GitHubは`avatar_url`／Googleは`picture`）
  - `stopped_at`:
    - 停止日時（`NULL`なら利用可能）
    - 荒らしのユーザーは削除せず停止する（削除すると、次のログインで新しいユーザーとして作られてしまうため）
    - 停止中のユーザーはログインできず、一時コードの交換もトークンの使用もできない
    - 停止はCLIスクリプトで行い、そのユーザーのトークンも削除する
  - `created_at`: データ作成日時（追加時に自動設定）
  - `updated_at`: データ更新日時（追加・更新時に自動設定）

## 外部トークン（external token / external_tokens）

- **概要**:
  - 外部ユーザーのログイン後に渡されるトークン
  - 発行時点から10*60秒（10分）の有効期間。延長はしない
  - 外部ユーザーが削除された場合、そのユーザーのトークンも削除される
- **項目**
  - `token`: トークン（`tokens.token`と同じ形式）
  - `owner`: トークンを発行した外部ユーザーの`external_users.id`
  - `expired_at`: トークンの有効期限（UNIXタイム）
  - `created_at`: データ作成日時（追加時に自動設定）
  - `updated_at`: データ更新日時（追加・更新時に自動設定）

## OAuthの状態（oauth state / oauth_states）

- **概要**:
  - 外部ログインの開始からコールバックまでの間だけ保持する情報
  - 発行時点から5*60秒（5分）で失効し、コールバックで使用したら削除する
- **項目**
  - `state`: CSRF対策用のランダム文字列。コールバックで受け取った値と照合する
  - `provider`: ログイン先のプロバイダー
  - `code_verifier`: commonsとプロバイダーの間で使うPKCEの検証用文字列（プロバイダーにはSHA-256のハッシュ値を渡す）
  - `code_challenge`: ブログとcommonsの間で使うPKCEのハッシュ値（ログイン開始時にブログから受け取る）
  - `redirect_uri`: ログイン後のリダイレクト先（許可リストにあるもののみ）
  - `expired_at`: 有効期限（UNIXタイム）
  - `created_at`: データ作成日時（追加時に自動設定）

## 一時コード（auth code / auth_codes）

- **概要**:
  - 外部ログイン後、ブログへのリダイレクトで渡すコード。ブログが外部トークンと交換する
  - トークン本体をURLに載せないためのもの
  - 1回限り有効。発行時点から60秒で失効し、交換したら削除する
- **項目**
  - `code`: ランダム文字列
  - `token`: 交換で渡す`external_tokens.token`
  - `code_challenge`: ログイン開始時に受け取ったハッシュ値。交換時に`code_verifier`と照合する
  - `expired_at`: 有効期限（UNIXタイム）
  - `created_at`: データ作成日時（追加時に自動設定）

## 共通コード群

各種のサイトで共通利用するコード群

### 都道府県（prefecture / prefectures）

- **概要**:
  - 都道府県コード（JIS X 0401）
- **項目**
  - `cd`
    - char(2):
  - `name`
    - varchar(8)
  - `kana`
    - varchar(16)
    - ひらがなで格納する（元データの半角カタカナを全角ひらがなに変換）
- **データの出典**
  - 総務省「全国地方公共団体コード」（<https://www.soumu.go.jp/denshijiti/code.html>）の「現在の団体」シートで、市区町村名が空の行
  - 取り込みは`scripts/import-areas.php`で行う（API経由の更新はしない）

### 市区町村（municipality / municipalities）

- **概要**:
  - 市区町村（全国地方公共団体コード）
- **項目**
  - `cd`
    - char(5):
    - チェックディジットなし（総務省の6桁コードの上5桁）
  - `pref_cd`
    - char(2): コードの先頭2桁
  - `name`
    - varchar(16)
    - 政令指定都市の区は市名を含めた名前（例:「横浜市中区」）
  - `kana`
    - varchar(32)
    - ひらがなで格納する（元データの半角カタカナを全角ひらがなに変換）
- **データの出典**
  - 総務省「全国地方公共団体コード」の「現在の団体」シート（市区町村・東京23区）と「政令指定都市」シート（政令指定都市の区）
  - 取り込みは`scripts/import-areas.php`で行う（API経由の更新はしない）
  - 元データから消えたコード（廃止された団体など）は自動では削除しない
- **補足**
  - 政令指定都市の場合、市のみの部分は格納しない（区のみを格納する）
    - たとえば「横浜市」は除外して「横浜市中区」「横浜市西区」･･･のように格納する

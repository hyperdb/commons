# API共通ルール

すべてのエンドポイントに共通するルールです。個別のエンドポイント仕様は`/documents/api/`を参照してください。

## ベースURL

- 本番: `https://commons.hyperdb.cloud/api/v1`
- バージョンはURLに含める（`/api/v1`）。互換性のない変更をする場合は`/api/v2`を新設する。

## リクエスト

- `GET` / `DELETE`: パラメータはクエリ文字列で渡す
- `POST` / `PUT`: パラメータはJSONボディ（`Content-Type: application/json`）で渡す
- 文字コードはUTF-8

## 認証

- ログイン認証（`POST /users/auth/{id}`）で発行されたトークンを`Authorization`ヘッダーに付ける
  - `Authorization: Bearer <短縮トークン>`
- 認証不要なエンドポイントは、個別仕様に「認証: 不要」と明記したもののみ
- トークンが有効期限内の場合、処理を行い有効期限を延長する（現状は仮で1時間）
- トークンが無い・無効・期限切れの場合は`401`を返す
- 権限レベルが足りない場合は`403`を返す

### 必要な権限レベル

認証が必要なエンドポイントでは、トークンの所有ユーザーの`user_level`（意味は`/documents/Entities.md`参照）で判定する。
権限レベルは`000` < `001` < `010` < `111`の単純な大小で比較する（桁ごとに個別の権限を表すものではない）。

| 操作 | メソッド | 必要な権限レベル |
|---|---|---|
| 取得系 | `GET` | `001`以上 |
| 更新系 | `POST` / `PUT` / `DELETE` | `010`以上 |

- 個別仕様に「必要な権限レベル」の記載がある場合は、そちらを優先する

## レスポンス

すべてのレスポンスは以下の共通形式（JSON）で返す。

```json
{
  "api_version": "1.0.0",
  "api_route": "/api/v1/users/abcd",
  "send_at": "2026-10-13 17:00:00",
  "message": "取得できました",
  "data": { }
}
```

| 項目 | 内容 |
|---|---|
| `api_version` | APIのバージョン |
| `api_route` | リクエストされたURL |
| `send_at` | レスポンス送信日時（`Y-m-d H:i:s`、日本時間） |
| `message` | 利用者向けの日本語メッセージ |
| `data` | 結果データ。一覧はオブジェクトの配列、該当なしは空配列 |

### エラー時

- `data.errors`に項目名をキーとしたエラーメッセージの配列を入れる（バリデーションエラーの場合）

```json
{
  "message": "パラメーターが正しくありません",
  "data": {
    "errors": {
      "password": ["パスワードは8文字以上です"]
    }
  }
}
```

- パスワード・パスワードハッシュ・トークン原文など秘密情報は、エラー時も含めレスポンスに入れない

## HTTPステータス

| ステータス | 使う場面 |
|---|---|
| 200 OK | 取得・更新・削除の成功 |
| 201 Created | 登録の成功 |
| 400 Bad Request | パラメータ不足・バリデーションエラー |
| 401 Unauthorized | 認証失敗・トークン無効 |
| 403 Forbidden | 権限不足 |
| 404 Not Found | 指定したリソースが存在しない |
| 409 Conflict | 登録しようとしたIDが既に存在する |
| 500 Internal Server Error | サーバー内部のエラー（詳細はログにのみ出力） |

## 一覧取得（ページング）

| パラメータ | 内容 | 既定値 |
|---|---|---|
| `page` | ページ番号（0始まり） | 0 |
| `rows` | 1ページあたりの件数 | 10 |

- 不正な値はエラーにせず補正する
  - `page`が負の値: `0`として扱う
  - `rows`が0以下: 既定値（`10`）として扱う

## ID

- 連番となる数値のIDは外部に出さない
- 数値IDを使うテーブルでは、`HashTools::generateSqid`で文字列化したものを項目`key`として返し、外部からはこの`key`で指定する

# common api

このプロジェクトは個人サイトで共通に利用するREST APIサーバーを構築することを目的としています。

## 動作環境

- PHP8.5
- MySQL5.7（本番運用のお名前サーバがこのバージョンのため）

## 運用環境

- お名前サーバー RSプラン
  - `https://commons.hyperdb.cloud`

## 技術スタック

- PHP8.5
- FlightPHP3
- MySQL5.7

## セキュリティ対策

- 連番となる数値のIDは使用しない
  - ID番号を利用する場合は`HashTools::generateSqid`を利用して文字列化したものを使用する。したがってIDを含む行セットを返す場合には項目`key`を追加して文字列化したIDも合わせて返却する。
- APIの利用時にはログイン認証時に発行されるトークンをBearer Tokenとして添付する。
  - API側はこのトークンが有効期限内でなければ処理を行わない。なお、有効期限内だった場合には有効期限を延長する（現状は仮で1時間）。
  - 当然ログイン認証（`users/auth`）はこの限りではない。

## テスト

- 各APIのテストはPHPUnitを利用して行う。
